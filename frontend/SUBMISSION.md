## 启动方式

**要开两个终端**，mock 和前端是两个进程，少开一个页面就是白的。

终端 1 —— mock 后端，这个窗口不能关：

```bash
cd frontend
node mock/server.mjs
```

终端 2 —— 前端：

```bash
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173

页面白屏的话先跑这条，能分清是后端没起还是前端的问题：

```bash
curl http://127.0.0.1:3001/api/products
```
