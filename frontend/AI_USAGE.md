# AI 使用说明（AI_USAGE）

各位老师好。由于我一开始接到项目后用豆包对项目做分析，期间豆包告诉我题目给的 AI 额度是要在前端页面里调用，给项目增加一些 AI 功能。我按这个理解想过怎么在前端发请求。后来才知道这个理解是错的，也是在那时才知道额度是给**开发过程**用的 —— 我这才去 VSCode 装了 Continue 插件，用智能体来做项目。

工具最终的选择是：Continue 反应不灵敏，主要工作改在 Qoder 里完成。下面第 2、3、4 节里发生在 Qoder 会话中的部分不在平台日志里，我在正文标注了是哪一个。

## 2. 模型选型（6 分）

| 我用它做什么 | 用的模型 | 为什么选这个 |
|---|---|---|
| "这作业要交什么" | 豆包 | 随手能问 |
| 日常问答、改代码 | Continue + `deepseek-v4.1-flash` | 想拿便宜的做主力 |
| 同上，换 `glm-5.3` / `kimi-k3.1-pro` | 想解决回答不全 | 换了贵的还是断在同一处 |
| 搭骨架、排查报错、看日志 | Qoder | 它能直接读文件、跑命令、看真实报错和服务器日志 |

**换模型的判断过程**：我一开始以为是模型太小所以回答被截断，换了更贵的还是断在同一个位置（都是"改动 3"那里），才确认是**网关输出长度限制，不是模型能力问题**。这个判断让我停止继续烧额度。

## 3. 挑 4 个场景写下来（5 分）

### 场景 1：让它解释报错，不是让它写代码

- **我想干什么**：解决报错
- **用的模型 / 为什么选它**：Qoder
- **我怎么问的**：报 `Tags with side effect (<script> and <style>) are ignored in client component templates`，这是报错信息，帮我检查代码并指出我的错误
- **它给了什么**：说 SFC 的 `<script setup>` / `<template>` / `<style scoped>` 三个块是**兄弟关系，不是嵌套关系**，`<style>` 必须在 `</template>` 之后。
- **我改了吗、为什么改**：改了，代码加错位置了。同一个错我犯了两次 —— 第一次贴进 `<template>`，第二次贴进 `<script setup>`（报 `Unexpected token (101:0)`）。第二次是因为我没看它的解释、只照做
- **怎么确认改对了**：`npx vite build` 通过，页面样式生效
- **结论**：直接用

### 场景 2：平台回答被截断，同一个问题问了 3 次（失败的一次）

- **我想干什么**：让平台给发布表单加"发布成功"的行内提示
- **用的模型 / 为什么选它**：Continue 里的 `deepseek-v4.1-flash`，想拿便宜的做日常改代码
- **我怎么问的**：把 `PublishForm.vue` 整个文件发给它，让它给"发布成功后显示绿色提示条"的改动
- **它给了什么**：它先调 `read_file` 把我的 `PublishForm.vue` 整个读了一遍（这一步卡了十几秒），然后给了"改动 1""改动 2"两段代码，写到"改动 3"就断了，第三条没给出来。我重试两次，都断在同一个位置
- **我改了吗、为什么改**：它的代码没接着要 —— 判断出来是输出长度限制不是模型问题，继续换更贵的也没用，改用 Qoder 重做这个改动
- **怎么确认改对了**：`npx vite build` 通过，页面上发布一次，绿色提示出来了
- **结论**：没用它的（只拿到一半），换工具重做

**这次浪费了什么**：多烧了 2 次调用。第 3 次才想到"断在同一处 = 限制，不是运气"，这个判断我应该第 2 次就做。

### 场景 3：AI 给的代码我删掉了一行

- **我想干什么**：给发布表单加前端校验
- **用的模型 / 为什么选它**：Qoder，因为要改的位置散在模板和脚本两处，需要它能直接读文件
- **我怎么问的**：让它给标题、价格、库存、分类四个字段加校验，错误显示在输入框下面
- **它给了什么**：给标题输入框加了 `maxlength="50"`，其余字段规则都对
- **我改了吗、为什么改**：我把 `maxlength="50"` 删了。因为加了之后根本打不出 51 个字，README L1-9「标题超长要拦下来」这条验收在页面上演示不出来。描述那个 `maxlength="200"` 我留着 —— 描述是选填，不判也不违规。这个不对称是有意的，不是漏了
- **怎么确认改对了**：标题敲 51 个字提交，输入框下方出现红字「标题最多 50 个字，当前 51 个」，请求没发出去
- **结论**：改了之后用

### 场景 4：我用 AI 做验证的一次

- **我想干什么**：查"下单成功了，但那句绿色提示一次都没出现"。而失败的红色提示一直正常
- **用的模型 / 为什么选它**：Qoder，因为要看的证据在后端控制台，不在前端，需要它能直接读服务器日志
- **我怎么问的**：我只说了一句「我没看到绿字」，没给猜测
- **它给了什么**：分两步。第一步它先 grep 了一遍文件，确认 `success` 这个标识符根本不存在 —— 结论不是"代码写错了"，是之前平台给的改动压根没落进我的文件。补上之后还不出现，它去看了 mock server 日志：

  ```
  POST /api/orders   -> 201
  GET  /api/products -> 200
  ```

  每次成功后紧跟一次重拉 → 定位到 `ProductList` 的 `v-if="loading"` 会**销毁**整个列表（`v-if` 是销毁不是隐藏），卡片里的本地状态活不过那一瞬
- **我验证了它说得对不对**：它说红字能活是因为失败不触发 `search()`、组件不销毁。我按这个说法去核对第三种情况 —— 发布商品成功也会重拉列表，但绿字正常，因为 `PublishForm` 不在 `v-if` 分支里。三个现象全对上，我才接受
- **我改了吗、为什么改**：按它的方案改了，把提示移到 `App.vue` 的 `notice`，`orderNo` 通过事件一层层带上去。原则：**谁不会被卸载，提示就放谁身上**
- **怎么确认改对了**：下单一次，顶部绿条出现且订单号正确；再下单一次，绿条跟着换新的单号；故意买库存 0 的商品，红字仍然正常
- **结论**：直接用它的方案，但接受之前我先自己找了一个反例去验

## 4. 一次被 AI 带偏的经历（必答）

- **它给了什么**：我问它这作业怎么用 AI，它说给的额度是要在前端页面里调用 API，增加一些 AI 功能。
- **当时为什么信了**：README 里全是接口字段和验收项，没有一句提到要实现 AI 功能，而"AI 使用 20 分"这一节**我读成了"要在项目里实现 AI"**。它说的正好接上我读错的地方。
- **怎么发现的**：不是我查出来的，是后来重新确认额度用途时发现的。我回去逐字读了 README 第 11 节，那一节考的是我怎么用 AI，交付物是这份文档本身。
- **最后怎么修的**：`frontend/` 里最终没加任何调用 AI 的代码，也没有密钥 —— key 只放在项目外的 `~/.continue/config.yaml` 和 `D:\project\ask.mjs`，`git log` 全量搜过，提交历史里没出现过。
- **之后改了做法吗**：涉及"要交什么"的问题只从 README 读，AI 用来解释题目，不用来**决定**题目，对它的说法保持怀疑。

**实际代价我照实说**：比看起来小。我当时只在脑子里想过怎么在前端发请求，**没有真的动手** —— Continue 插件是知道正确用途之后才装的。所以这次带偏没浪费编码时间，浪费的是方向判断的时间。但风险是真的：如果照着做了，会在 `frontend/` 里留一个真实 API key，或者留一段调用不通的死代码。

## 5. 成本（4 分）

| 问题 | 我的回答 |
|---|---|
| 有没有"一次把整个项目/整个文件塞进去"？为什么？ | 有，起步时整个项目发给 Qoder 要框架。但这次是划算的 —— 目录结构和三个工具文件一次成型，后面没返工。后来切成一次一块，是因为整包会改到不相关文件。 |
| 有没有同一个报错连续问了很多次？后来怎么改的？ | 在调用 deepseek 的时候，平台回答截断，我重试了 3 次都断在同一处。第 3 次才判断出这是输出长度限制。这也是最终换回 Qoder 的直接原因。 |
| 如果额度只有 10 元，你会怎么调整？ | 骨架和排查全部用 Qoder，平台只用来问"解释这段 Vue 行为"这类一问一答、不需要它读我文件的题。 |

**我认为不值得问 AI 的三类问题**，都是我自己零成本解决的：

1. **接口返回长什么样** → `curl` 打一遍，2 秒，免费。问 AI 反而慢，因为它手上没有真实数据。
2. **代码有没有语法/位置错误** → `npx vite build`，十几秒，免费，不改我任何代码。场景 1 那个重复声明和标签位置就是它抓的。
3. **金额换算对不对** → 命令行直接跑 `money.js` 的换算。`19.9 * 100 = 1989.9999999999998` 这种浮点坑，跑一次就有确定答案，问 AI 只会得到"应该没问题"。
